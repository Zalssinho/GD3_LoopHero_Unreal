# LoopHero_Unreal

Ce qui a été réalisé pour le rendu du 07/04/2026 :

Ajout d’un mini-jeu sur la case de récolte de bois pour la construction de la maison. Dans ce mini-jeu, le joueur doit cliquer le plus rapidement possible sur l’arbre situé en face de la caméra afin de faire tomber des bûches de bois au sol, le tout dans un temps imparti. Si le joueur ne parvient pas à réussir sa collecte, il doit recommencer depuis le début.

Ajout d’un HUD spécifique au mini-jeu, comprenant un timer, le nombre de bûches à collecter ainsi qu’une barre de progression pour améliorer le retour visuel.

Les dialogues ont également été modifiés afin d’améliorer l’ergonomie et la compréhension pour le joueur.
