# LoopHero_Unreal

Ce qui a été réalisé pour le rendu du 07/04/2026 :

Ajout d’un mini-jeu sur la case récolte de bois pour la construction de la maison. Dans ce minijeu le but est de cliquer le plus vite possible sur l'arbre en face de la caméra pour faire tomber de buche de bois au sol dans un temps imparti, si le joueur ne réussit pas ca collete il doit reprendre de zéro. 

Ajout d'un HUD propre au minijeu avec le timer, le nombres de buches à collecter et une progress bar pour le coté visuel. Les dialogues ont été modifié pour l'ergonomie du joueur.
